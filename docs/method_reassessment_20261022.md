# 方法重审与继续研究的门槛（2026-10-22）

验收要求是同时具有实质方法创新和公平真实实验中的优势。现有版本两项均未达到。本记录保存负面发现和下一候选假设，不把实验目标写成已得到的结论。

## 1. 当前目标降为对照

在前一轮已经查看过的合成数据上，将训练上限改为 300 epochs / 1200 steps，patience=40，学习率 0.003，验证选择 rank∈{2,4,8}，完整运行种子 7/17/29。每次划分为 4/2/2 个合成供者、80/40/40 个细胞、8 个基因。使用相同训练/验证/评价协议，记录早停和选择结果。

| 方法 | 三个种子的评价 deviance（低为好） | 均值 | 种子间样本标准差 |
|---|---|---:|---:|
| `joint_relative` | 2.998998, 3.043808, 3.042959 | 3.028588 | 0.025629 |
| `joint_absolute` | 2.805841, 2.824871, 2.696698 | 2.775804 | 0.069165 |
| 固定标签 `fixed` | 1.944676, 2.010749, 2.019558 | 1.991661 | 0.040928 |
| 降秩回归 | 1.910088, 1.910088, 1.910088 | 1.910088 | 确定性算法，相同数据重复不增加证据 |

这些是**已暴露开发数据上的优化诊断**，不是新的独立测试，更不是作者 SOTA 排名。种子标准差不是患者置信区间。300 是训练上限，早停后的实际步数保留在逐运行 selection 文件。三个种子全部报告，不能仅保留最好的一次。

机器可读指标和全部候选选择记录见 [开发诊断报告](../reports/objective_audit_20261022.json)。安装仓库后，运行 `python experiments/audit_current_objective.py --output runs/objective_audit_replay` 可重新生成这批合成数据并复现；输出目录必须不存在。该独立重放已执行，三个种子的全部指标与首次运行一致，脚本通过 Ruff 检查。这仍只是复现负面的开发结果。

结果不支持“只需增加训练轮数就能挽救当前目标”的解释，但不能据此证明它在所有真实数据上都失败。[已有理论](theory.md)也给出一个明确失败条件：若基线计数均值位于可行标签集合中，相对悲观目标的唯一最优均值就是基线。当前数值失败并不自动证明该条件在每个训练块上都成立。

决策：保留 `joint_relative` 及其 LP、反例和消融实现；停止把它作为已有性能支持的主方法扩展。冻结这批开发结果，下一主方法的最终验证需要新的未参与选择的真实患者测试集。

## 2. 前作排除了哪些简单创新叙述

- [Contrastive Pessimistic Likelihood Estimation](https://arxiv.org/abs/1503.00269) 已有相对基线的悲观似然母题；[Learning from Interval Targets（NeurIPS 2025）](https://proceedings.neurips.cc/paper_files/paper/2025/hash/570641fd4b0340cc8ba6320955de891f-Abstract-Conference.html) 已研究区间标签的 min-max 回归。
- [CELLO（2026-09）](https://arxiv.org/abs/2609.36429) 已有位置查询、距离衰减上下文与 cell/patch 联合监督；[GHIST+](https://github.com/SydneyBioX/GHIST_plus) 已结合细胞、邻域、组织和异构面板信息。不能将这些模块组合直接称为原创。
- [Pixel2Gene](https://github.com/yaosicong1999/Pixel2Gene) 已使用分子坐标聚合后的网格监督；[DeepSpot2Cell](https://github.com/ratschlab/DeepSpot2Cell) 已有 spot 到 cell 的聚合学习。总量监督不是新发现。
- [Proseg](https://github.com/dcjones/proseg)、[ResolVI](https://docs.scvi-tools.org/en/stable/user_guide/models/resolvi.html)、[MisTIC](https://github.com/yunguan-wang/MisTic-Wanglab) 已覆盖概率观测/分子归属和去污染；[PACE](https://github.com/ecool50/PACE) 已区分生物与技术空间核。PPP、EM、双核或标准正交化公式本身都不构成新贡献。

这些检索支持的是具体前作差异分析，不能证明所有相关文献中都不存在下面的组合。

## 3. 唯一保留的候选主线：从观测分子直接学图像预测器

以分子坐标和基因身份作为训练观测，将细胞归属边缘化。图像模型输出潜在细胞表达；校准的测量机制把它映射回观测分子强度。示意式为

\[
\lambda_{dg}(u)=\beta_{dg}(u)+\sum_i K_\psi(u\mid G_{di},a_d)\,\mu_{\theta,g}(H_{di},C_{di}),
\]

其中 G 为几何，a 为测量平台/批次条件；K 的积分、单位、背景和组织截断必须明确。PPP 的基本负对数似然为

\[
\sum_{d,g}\int_{\Omega_d}\lambda_{dg}(u)\,du
-\sum_{d,t}\log \lambda_{d,g_t}(u_t).
\]

这只是候选观测模型，不是已实现的新主方法。PPP 条件独立性、基因亚细胞定位和批次差异均需检查；存在过度离散时不能声称 Poisson 自动正确。

需要研究的实质问题是：共享的图像到表达函数、跨组织几何和有限独立校准信息，能否区分“真正状态变化”和“归属/扩散机制变化”；哪些状态方向在校准有误差时仍可稳定预测。仅写出 K 满秩或标准 Fisher/Schur 补公式，不足以作为新理论贡献。

约束条件：

1. 不能为每个样本自由选择 K 来解释表达误差；必须限制共享机制的容量并审计适用域。
2. 核内分子是经位置选择的子集，不能直接当作无偏的完整细胞归属校准。独立蛋白/膜通道也有分割误差，不等于人工真值。
3. 图像先验无法从完全不可识别的观测中创造 RNA 证据。对相同观测分布的状态解释，应保留不确定性。
4. 校准和超参仅使用训练/校准供者；测试部署只读取 H&E 与明确允许的几何信息，不能读取测试 RNA 或其 embedding。

## 4. 对手、消融和退出条件

主对手不能只用旧模型或常规 ridge。比较至少包括作者完整 CELLO/GHIST+（在代码、权重和输入可获得时）、GHIST、Pixel2Gene 的适配任务，以及同编码器下的以下组合：

| 对照 | 排除的替代解释 |
|---|---|
| 原始分割标签 → 同一个强预测器 | 更强表征或预测头本身就足够 |
| Proseg/MisTIC/ResolVI/DeSpotX 纠正标签 → 同一预测器 | 普通去污染预处理就足够 |
| 同一观测似然＋固定几何核 | 收益只来自标准 forward likelihood |
| 独立校准核＋两阶段学习 | 收益只是多用了校准信息 |
| 联合学习/交叉拟合的校准方案 | 候选耦合学习是否有额外价值 |
| oracle 核、无校准、错误校准（模拟诊断） | 校准上限、不可识别和错设敏感性 |

所有可用方法使用相同患者划分、基因和评价单位；作者完整系统先使用推荐配置并验证训练充分，另报告相同特征/预算的机制比较。不能通过削减对手训练、用测试标签归一化预测、挑基因或丢掉难患者获得胜利。

真实实验必须同时报告主要预测指标、同类型内状态指标和全部患者结果。独立蛋白支持用于检验对应生物状态，不代替所有 RNA 的真值。患者很少时报告探索性个体结果，不以细胞或随机种子充当独立患者。

**继续门槛：** 候选方案须在未参与方法选择的真实患者上超过预先指定的最强公平对手，关键消融须支持所宣称机制，且前作审查确认贡献不限于已有算法拼装。如果只优于原始硬标签，却不优于“去污染→同一强模型”，不继续扩大该论文主张。没有预设必胜结论。

## 5. 真实数据准备

- GSE311609：已定位 B15/B16 的真实 cell matrices、分子坐标、边界和配对 post-Xenium H&E。影像为包含多个组织块的 CZI，尚须明确组织块对应、坐标变换和配准 QA；同样本不等于已配准。
- [Zenodo 21713660](https://zenodo.org/records/21713660)：公开 CC-BY-4.0 的四个 core，包含同组织 Xenium、COMET、H&E、变换矩阵和 COMET-derived InstaSeg masks。已用 HTTP Range 实际读取 ZIP 目录：UnumLocalia 为 9540 个条目，仅目录读取约 1.33 MB，能选择性取得数据；不是已下载并验收全部 2.23 GB。四个 core 不应未经供者核对当作四个独立患者。
- 该 Zenodo 的默认 cell quantifications 使用 Xenium masks。独立验证必须使用另附 COMET masks 重新量化，不能把默认表冒充独立归属真值。
- GSE250346 的部分 transcript GraphSAGE embeddings 使用基因身份，不能冒充纯 H&E 特征。

文件下载、配准验收、方法训练与 SOTA 结果是不同状态；本次尚未产生真实 SOTA 比较成绩。
