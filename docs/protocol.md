# 实验协议与可解释范围

本仓库实现了分子归属歧义下的结构化弱监督、强基线和完整实验调度。合成数据用于检查代码路径，不证明真实分子状态可被 H&E 恢复；条件负二项模型、稀疏 LP 或 minmax 形式本身也不代表已确立的方法创新。

## 研究问题

在留出的患者中，图像特征是否提供了超过预先定义的细胞组成协变量的表达预测信息？更严格的后续问题是：这种增益是否发生在相同粗粒度细胞类型内部，并且能在测量、分割和污染处理变化后复现？

这是关联预测问题。观测性 H&E–RNA 配对不能单独识别基因到形态的因果效应。组成变量不完整时，“超过当前协变量基线”也不等于“排除了全部组成效应”。

## 当前模型

对细胞 `i`、基因 `g`，计数模型使用负二项似然：

```text
Y_ig ~ NB(mu_ig, theta_g)
log(mu_ig) = log(s_i) + b_g(C_i) + [V f_phi(X_i)]_g
s_i = library_size_i / median_training_library_size
```

先拟合仅协变量的基线 `b`，随后复制并冻结该基线，再训练低秩图像增量。模型学习逐基因的正 dispersion。这里的“低秩状态”只是参数化的隐变量；没有正交性、唯一性或可识别性保证，不能直接把某个隐维度命名为确定的生物通路。

当前基线包括 image/covariate/residual ridge、协变量 NB、条件 NB，以及同特征的训练均值、Poisson MLP、降秩回归、残差 PCA+ridge、正则化 partial CCA 和 donor-crossfit residual ridge。普通 residual ridge 与交叉拟合版本分别报告。后者的 nuisance 在训练患者内部逐折排除被预测患者，推理 nuisance 再拟合全部训练患者；它不自动提供正交性或因果保证。正则化线性 CCA 和残差 PCA 是独立实现的经典对照，不冒充 Probabilistic Partial CCA 或 ResidPCA 作者系统复现。

负二项训练使用观测计数和 library size；推理输出的是标准暴露量下的 rate，不要求测试 RNA。评估 count NLL 时使用测试 library size 作为 exposure 属于**给定测量深度的条件评分**，不表示模型能仅凭 H&E 预测绝对 RNA 总量。

## 联合歧义训练

`geometry.py` 将已配准分子观测构造成稀疏候选 owner 图，最后一列为显式背景。分子质量在所有可行 owner（包括背景）之间守恒；细胞内总质量本身不必守恒。`BudgetedLabelSet` 限制全图几何代价和背景质量，使用 HiGHS 线性规划计算最坏标签、精确边际界和线性状态对比界。无共享预算时使用精确逐行优化。变量是可分配质量；有共享预算时可能得到分数归属，不能称整数分子恢复。

`weak_training.py` 在相同冻结图像特征、组成基线和患者划分下训练 11 种目标。主方法 `joint_relative` 最大化预测器与冻结基线的 Poisson 损失差，其 count-factorial 项严格抵消，使内层目标对归属线性。内层最优解 detach 后计算外层次梯度，不对 HiGHS 求导。基线仍用 NB 拟合，弱监督头的 dispersion 冻结；不声称实现了可训练 dispersion 的鲁棒 NB 内层。

- `interval_relative` 使用同一预算集合的精确 marginal bounds；超过查询上限直接失败，不悄悄换成较宽区间。
- `fixed`、`optimistic_relative`、`joint_absolute`、`random_assignment`、`ensemble` 分离固定标签、悲观性、准损失与增强的影响。`joint_absolute` 省略随标签变化的 factorial，是最坏准损失，不是完整 NLL。随机 LP 目标取可行顶点，不是均匀多面体采样。
- `core_only` 的训练和验证选择目标仅为结构上唯一 owner 的分子，预测尺度不同，标记为不进入全 RNA 主排名。其他默认方法使用固定观测全计数进行验证选择。真实核内性质需要独立核注释，不能由图算法自己证明。
- `aggregate` 聚合真实细胞 owner 连通分量，不是固定网格模型。存在背景交换时，默认固定分割聚合标签不具有归属不变性；`aggregate_background: exclude` 才排除能与背景交换的分量。
- `no_geometry` 与 `no_background_budget` 分别去掉共享预算。组成项、容量、rank 由配置变体控制。

原始 owner 必须在支持图内且满足预算，汇总计数必须与输入整数 counts 完全一致。半径是已配准中心距离代理，不是真实膜边界；`is_core` 为独立注释声明。预算与半径需在看测试效果前校准。按基因筛选时，删去基因固定在原 owner 并扣除其预算，所以剩余图是条件可行集，不是未经条件化的集合投影。

当前实现保留完整图块，拒绝在训练 runner 内任意下采样 cells。内层图是稀疏的，但选定 cells×genes 标签/特征仍有内存上限；约束上限会显式拒绝过大的任务，不会自动近似并继续报告精确结果。

## 供者划分与模型选择

1. 下载后先建立供者映射。相邻切片、不同 panel、重复扫描、同一组织块和 TMA 上的重复供者全部归入同一组。
2. 在拟合任何数据依赖变换前确定 train/validation/test 供者。禁止把细胞随机分到不同集合。自定义划分必须覆盖所有供者且每位只出现一次。
3. 标准化参数、基因过滤、方差筛选、表达归一化参照、PCA 或其他学习得到的变换都只能由训练集拟合。若某项变换在当前版本未实现，应在外部完成并记录其训练来源。
4. rank、学习率、正则化和早停只由 validation 决定。选好模型后才评价 test；不能反复查看 test 再修改候选集并仍称其为最终测试。
5. 每次保存配置、随机种子、供者划分、基因顺序、输入来源、变换参数、检查点和预测，保证复现。

GSE311609 的六位肺癌 5K 供者适合可行性检查，但一个随机划分的测试供者可能过少。`suite.py` 已实现预先锁定的外层供者 folds、LOO 和可选 TMA 等分组；每折保留内部验证患者。自动分组不提供疾病分层，需分层时使用显式 folds。所有 seed 使用相同外层拆分；每位患者恰好出现于一个外层测试折，先在患者内平均 seed 再统计。

任务生成记录固定配置摘要；恢复时拒绝配置改变，失败保留账本。组列必须将一个 donor 绑定到一个 group；跨 group 的重复患者要先合并关联组。图像协变量分类器记录训练/选择患者，不能跨外层折复用已接触该折测试患者的分类器。

不得把“来自同一个患者的不同记录”算成外部验证。预训练编码器和公开基准的来源也要检查重复；冻结编码器并不自动消除预训练患者重叠。

## 部署输入与 oracle 分析

将实验分开报告：

| 分析 | 允许输入 | 结论 |
| --- | --- | --- |
| 图像部署实验 | H&E 特征、仅从 H&E 得到的细胞类型概率和邻域组成 | 在这些图像管线质量下的预测性能 |
| RNA-oracle 敏感性实验 | 实测 RNA 推导的类型或组成 | 已知分子协变量时图像的增量信息，不是可部署性能 |
| 合成实验 | 人工计数、特征和协变量 | 实现是否按预期运行 |

元数据中的 `cell_type` 可用于事后分层评价，但不可自动输入图像部署模型。避免直接把目标基因定义的细分状态作为“要控制的类型”，否则可能把待研究信号本身消除。计划研究状态时，事先确定粗粒度类型和目标基因；可增加标记基因与评价基因不重叠的敏感性分析，但这也不能保证完全消除标签依赖。

如果类型估计、分割或邻域构造借助了 Xenium DAPI、转录本或 RNA 标签，其来源须逐项记录。将 RNA oracle 编码成 one-hot 后命名为“协变量”不会使它成为图像输入。

`image-covariates` 用训练患者粗类型注释监督线性图像分类器，以内部验证患者选择 epoch，然后只从图像特征生成全体细胞的类型概率及同切片近邻均值。它不读取测试类型来拟合或调参。这个流程允许训练监督来自 RNA 粗注释，但必须明确其来源、类型定义和测试时可用输入；不等于标签无需来源审核。

## 评价与负对照

首先计算每位供者的指标，再对供者等权平均，避免细胞数最多的患者主导结论。比较模型时使用相同患者和相同基因，并报告模型间的配对差值。

- **整体预测**：标准化表达误差和逐基因相关性是基础描述。低方差或常量基因的相关性未定义，应标记并报告可评价数量，不能偷偷当作 0 或 1。
- **条件增量**：优先报告条件模型相对组成基线的 NLL 或预测误差改善。图像增量为正并不自动对应可解释、可迁移的细胞状态。
- **同类型内部评价**：在足量细胞的供者 × 粗类型层内报告误差和相关性，并记录缺失层、有效基因数和样本量。单个层内基因恒定时不能通过跨类型拼接“补出”相关性。
- **置换负对照**：在同一供者、同一粗类型内置换图像特征，保留这些组的边际分布并破坏细胞级配对。邻域、空间位置、分割质量和其他连续协变量仍可能失配，因此这是诊断性负对照，**不是有效性已证明的条件随机化检验或因果检验**。
- **不确定性**：在患者层面重采样来描述患者间差异。细胞 bootstrap 会低估患者间不确定性；仅一至数位测试患者的 bootstrap 区间同样不可靠，必须报告患者数和逐患者结果。

同患者同类型的随机置换也可能破坏空间自相关。需要更强的后续负对照时，可以预先定义空间块和组成匹配方案，但不得在观察到结果后选择最有利的置换方式。

`evaluate-states` 使用事先规定的有符号基因程序，在患者×粗类型内与 protein/IF/expert/synthetic 标签比较 AUROC、average precision 和分数差，不在测试标签上学习阈值或权重。它无法验证用户声明的标签来源是否真实独立；需审计是否共用了 Xenium mask 或目标 RNA。

`contrast-bounds` 输出的是声明候选图与预算下的尖锐线性上下界。范围跨过 0 时标记 `unresolved`，不是将不确定病例删去后报告更高精度。可行范围与患者抽样 bootstrap 的含义不同，不能互换为置信区间。基因程序的 log-rate 分数也不能直接套用原始 counts 的线性界。

`bound-risk` 要求同一线性对比、同一计数单位的合成/独立真值，以及所有对比的完整真值表。每个对比只能属于一个患者。接受规则使用预给宽度阈值及范围方向，不能根据 test truth 选择阈值；没有接受对比的患者依然贡献覆盖率 0，而风险为空值。完整定义和 `stress-case` 的 null 可行性见证见 [stress_and_selection.md](stress_and_selection.md)。数学命题及固定暴露量、权重、假设类、患者独立性的适用条件见 [theory.md](theory.md)。

外部作者模型通过固定 revision 的执行器和输出格式适配进入审计。GHIST 原生 log1p(raw counts) 与本项目 normalized rates 的单位不同；只在明确统一训练目标协议后进入同一 rate 排名。Pixel2Gene 按固定共同 mask 汇总网格。Path2Space 的区域输出、去污染方法、RNA-oracle 输入分开报告；具体契约见 [sota.md](sota.md)。

## 污染、计数噪声和目标定义

负二项似然可描述过度离散，但不是完整的 Xenium 污染或分割误差模型。它不能自动区分真实细胞状态与邻近细胞转录本误分配。

计划在原始计数与合理的重分割/去污染处理上做敏感性分析。SPLIT 或其他处理后的输出也是估计量，不能作为独立金标准；与处理后计数更相关不必然意味着更接近真实生物学。如果去污染算法本身使用图像信息，还需检查循环验证。

将 RNA 计数随机拆分可用于检查特定计数模型下的采样噪声，但不等于获得独立生物重复。343 基因面板的结论限于已测目标，不能外推成全转录组或任意通路恢复能力。

## 从可运行框架到可投稿证据

建议依次通过以下阶段，每阶段都保存失败和排除记录：

1. **管线检查**：测试通过，合成示例可跑通，表达/图像/细胞 ID 和供者划分一致。
2. **真实数据验收**：逐样本配准叠图、计数 QC、图像来源、面板一致性和预训练重叠审计完成。
3. **强基线比较**：在固定外层供者划分中运行已实现的 ridge、crossfit、CCA/PCA、计数头和歧义目标；再以真实作者配置执行可取得的 SOTA，并记录无法复现的方法。
4. **状态证据**：在同类型内部、组成匹配和负对照下仍有增量，并检查污染敏感性与外部数据复现。
5. **方法创新判断**：只有发现可重复的基线失效并提出必要的新估计机制，才主张方法贡献。单纯叠加模型模块、冻结编码器或使用负二项分布都不是充分创新。

当前版本已提供上述核心方法代码，但没有提供真实队列性能、疾病机制结论、新理论保证或论文录用预测。MOSAIC Visium SD 可支持区域级验证，不能填补单细胞真值缺口。
